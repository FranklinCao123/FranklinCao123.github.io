## Overview

This project investigated the electromagnetic behavior of a ferrite microwave circulator through three-dimensional finite-element simulation. A parameterized model was developed using the COMSOL RF Module to analyze and optimize nonreciprocal microwave transmission.

## Key Work

- Solved the frequency-domain Maxwell equations with an anisotropic permeability tensor to model gyromagnetic effects under an external bias field.
- Analyzed electric-field distributions and time-averaged power flow, and performed parametric sweeps using the S-parameters S<sub>11</sub>, S<sub>21</sub>, and S<sub>31</sub>.

## Highlight

The optimized design achieved an operating frequency range of **8.8–9.5 GHz** and a minimum reflection coefficient of **S<sub>11</sub> = −43.04 dB**.
