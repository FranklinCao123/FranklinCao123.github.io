## Overview

MatAgent-WBG is an ongoing AI agent project for scientific research. The project explores how agent-based systems can organize reasoning, tool use, and multi-stage workflows for domain-specific scientific tasks.

## Current Focus

- Developing a modular agent workflow for scientific problem solving.
- Connecting model reasoning with domain knowledge and research tools.
- Improving the reproducibility and efficiency of multi-step scientific workflows.
